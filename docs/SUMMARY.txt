🗄️  SCHÉMA BASE DE DONNÉES

TABLE: monsters (Données complètes + métadonnées)
├── id (INTEGER, PRIMARY KEY)
├── monster_id (STRING, UNIQUE INDEX)          ← Recherche rapide
├── state (ENUM, INDEX)                        ← Groupement États
├── monster_data (JSON)                        ← Toutes les données
├── created_at, updated_at (TIMESTAMP)
├── is_valid, validation_errors (BOOLEAN, JSON)
├── reviewed_by, review_date, review_notes
├── transmitted_at, transmission_attempts
├── invocation_api_id, last_transmission_error
├── generated_by, generation_prompt
├── image_path, metadata_extra (JSON)
└── Relation: (1) → (N) state_transitions

TABLE: state_transitions (Historique complet)
├── id (INTEGER, PRIMARY KEY)
├── monster_db_id (INTEGER, FOREIGN KEY, INDEX)
├── from_state, to_state (ENUM)
├── timestamp (TIMESTAMP)
├── actor (STRING)                             ← system|admin|user
└── note (TEXT)
